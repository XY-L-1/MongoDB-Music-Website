# MongoDB-Music-Website
Using MongoDB to store the music information on the website.

Step 1: Install dependencies
"npm install" 

Step 2: Start the website
"npm start"

# Note:
Since I use MongoDB personal account, you will have to use your own account and replace the login information in the db.js

Create an Atlas MongoDB account. You will be using Atlas, not a local database
Create a database in the Clusters, name the music database music_db (or whatever you want) with a collection called songs (or your choice)

Use the mongoose module to interact with the MongoDB database
'npm install mongoose'

Click the connect button on the MongoDB website, and find your best choice. 

Boom, done.
